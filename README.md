# Car Dealership Analysis

A Data Analysis project that explores Indian car dealership data using **Python, SQL, and Power BI**. The project focuses on cleaning raw data, analyzing sales-related insights, and creating an interactive dashboard for business decision-making.

## Project Overview

This project demonstrates an end-to-end data analysis workflow:

* Data collection and cleaning
* Data preprocessing with Python
* SQL-based analysis
* Interactive Power BI dashboard
* Business insights from dealership data

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib)
* SQL
* Power BI
* Microsoft Excel
* Git & GitHub

## Project Structure

```text
Car-Dealership-Analysis/
│── Car_RawData/        # Raw dataset
│── PyData/             # Python scripts and notebooks
│── PowerBiVisual/      # Power BI dashboard files
│── car_imgData/        # Dashboard screenshots and visuals
│── README.md
```

> **Note:** The `car_image` folder is intentionally excluded from the GitHub repository.

## Workflow

1. Import raw dealership data.
2. Clean and preprocess the dataset using Python.
3. Perform data analysis and identify trends.
4. Build an interactive Power BI dashboard.
5. Generate business insights.

## Dashboard Highlights

The dashboard provides insights such as:

* Sales overview
* Revenue trends
* Brand-wise performance
* Key business KPIs
* Interactive filtering

> Dashboard screenshots can be found in the `car_imgData` folder.
